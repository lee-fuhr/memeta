## The big picture (30-second version)

**The problem:**
LLM memory systems were fragmented. Each project solved one problem perfectly:
- mem0: How do we store semantic memories? (vectors + graphs + KV)
- Letta: How do we manage context windows? (hierarchical tiers)
- Zep: How do we reason about time? (temporal knowledge graphs)
- SimpleMem: How do we save tokens? (semantic compression)
- LangChain: How do we make memory modular? (composable blocks)

**The insight:**
These aren't competing approaches. They're complementary. Agents need ALL of them.

**The solution:**
Memory Meta synthesizes all five approaches into one platform. Not "better than" each project—"builds on" each project.

**Your positioning:**
"Standing on the shoulders of giants" — we give full credit, learn from each, and prove they work better together than separately.
