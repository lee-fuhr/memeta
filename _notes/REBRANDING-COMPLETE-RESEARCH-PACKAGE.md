## Key findings summary

### The memory systems landscape has matured into 5 camps

| Philosophy | Leader | Key insight |
|-----------|--------|------------|
| **Hybrid storage** | mem0 (46.8K stars) | Different data types need different retrieval |
| **OS hierarchy** | Letta (13K+ stars) | Context window is the bottleneck |
| **Temporal KGs** | Zep/Graphiti (4K/20K stars) | Time matters in relationships |
| **Compression** | SimpleMem | Semantic compression = token efficiency |
| **Modularity** | LangChain/LlamaIndex (100K+/50K+) | Blocks, not monoliths |

### Memory Meta's unique position

**Not competitor. Synthesis.**

- mem0 chose one approach (triple storage)
- Letta chose one approach (OS hierarchy)
- Zep chose one approach (temporal KG)
- SimpleMem chose one approach (compression)
- LangChain/LlamaIndex chose approach (modular blocks)

**Memory Meta:** Runs all five simultaneously, plus cognitive features, plus autonomous operation.

**Result:** 101 features vs. 8-20 features per other system.

### Why this positioning works

1. **True:** You actually do synthesize all approaches
2. **Honest:** You explicitly credit prior work
3. **Differentiating:** "All approaches" is genuinely unique
4. **Collaborative:** Friendly to other projects, not competitive
5. **Research-forward:** Positions Memory Meta as synthesis/integration platform, not a replacement

## Messaging framework (core narrative)

### The problem
LLM memory systems were fragmented. Each team solved one problem:
- mem0: "How do we store semantic memories?"
- Letta: "How do we manage limited context windows?"
- Zep: "How do we reason about how memories change?"
- SimpleMem: "How do we save tokens?"
- LangChain: "How do we make memory modular?"

But agents need ALL of these capabilities working together.

### The solution
Memory Meta synthesizes all five approaches into one platform that:
- Stores memories in multiple modalities (vector + graph + KV + temporal)
- Optimizes context windows through hierarchical management
- Reasons about temporal change
- Compresses memories efficiently
- Enables modular retrieval patterns
- Operates autonomously

### The attitude
"We're not building competitors. We're building the integration layer."
